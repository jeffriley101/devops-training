Delivered behavior
  The ivory/green surfaces and yellow Submit button remain. Idle timer label is
  Stopwatch, active label Stop Stopwatch, and retained time uses Resume Stopwatch.
  Stopwatch and Pristine P-Chart are alternatives separated by a small “or”. The
  elapsed-time display is within Stopwatch's group and has its own accessible name.
  The shared Pristine description is removed. Each method instead has hover/focus
  help and a separate 44px information button which never starts that method:
    Stopwatch: Start and stop your practice timer.
    Pristine P-Chart: Use your microphone to track practice.
  These descriptions match existing elapsed timing and microphone activity detection.
  Open help stays within its method group so it does not cover the alternative.
  Help supports touch toggle, keyboard focus, Escape, focus departure and outside
  activation. It does not rely on title attributes.

  Switching from an active Stopwatch to Pristine explicitly asks to pause. Cancel
  keeps Stopwatch running. Continue retains elapsed time and the form draft, then
  opens the existing Pristine experience; it does not fill minutes, save a chart,
  or merge credited time. Retained time includes fractional seconds internally;
  display and existing credited-minute rounding remain unchanged.
  Pristine still uses explicit Enable Microphone & Start, Pause, Save & Finish,
  unsaved-work confirmation and Leave Without Saving. Background capture is stopped
  through its existing lifecycle handling. A same-origin, account-bound Web Lock
  prevents concurrent practice methods in different tabs. Locks are released on
  stopping, leaving, background microphone shutdown and account changes.
  Current secure-context Web Locks support is required to start these methods.
  If coordination is unavailable or another method holds the lock, an explicit
  message is shown; manual entry and the draft remain available.

  What did you work on? is the details control's sole summary/heading. All 23
  checklist values remain. Notes uses the exact placeholder "Notes." and an accessible
  optional label. The visible date heading is removed; the picker retains its
  accessible label, original today default, allowed dates and validation. Existing
  date and duration calculation functions and server validation are unchanged.

  Checkbox labels are exactly Include in Leaderboards and Include in Team Standings.
  Both default to checked for a new form. Existing names, submitted Boolean values,
  eligibility and no-team choose/continue behavior are unchanged. Long explanatory
  paragraphs are removed; actual team-status feedback remains. A checked option
  makes no promise of rewards or competitive credit.

  The separate Manage Verifiers button is removed. Add verifier… is an action
  option in the existing select, never a recipient. Selecting it first restores
  the prior verifier value, saves the existing account-bound draft, pauses/retains
  Stopwatch, and opens /trusted-verifiers?return_to=p-book. Focus alone does not
  navigate. Returning restores minutes, chosen date, notes, checklist, both Boolean
  choices, verifier and elapsed time. A failed draft/time write blocks navigation
  with feedback instead of silently discarding work. Drafts retain the existing
  account/session binding and 30-minute lifetime. Submission excludes the action
  marker explicitly, in addition to the unchanged server recipient validation.

  All four statistics are native buttons opening one compact native dialog:
    This Week’s Reported Practice: seven Monday–Sunday time bars.
    Career Reported Practice: cumulative reported-time line over all saved history.
    Saved Practice Days: month calendar, positive saved-time days, all-time count.
    Saved Charts: P-Chart counts by practice week, including empty intervening weeks.
  The whole card supports keyboard/touch and cannot submit the form. The dialog
  focuses Close chart; Escape/Close returns focus to its opener. Exact-value tables
  supply text alternatives and keyboard scrolling. The calendar explicitly labels
  its selected month; all-time totals stay separately labelled. Charts do not animate.

  Sources are existing authorized /practice-charts and /practice-charts/totals,
  fetched fresh with no-store. The former returns the full authorized saved dataset,
  not the visible ten rows or the 100-entry client cache. Career/weekly totals are
  checked against the authoritative totals response before rendering. Positive
  duration_seconds defines practice days; all records, including historical zero-time
  charts, define chart count. Practice dates define days/weeks. Existing exact-seconds
  formatter is reused. Charts are not represented as distinct sessions, do not invent
  category minutes, and do not deduplicate potentially overlapping credited practice.
  Fetch generations and account/session checks discard stale/private responses on
  close, hidden page, navigation or account change. No new endpoint or permission
  grant was added. Open-account raw statistics remain open through their existing
  source permissions; gated rating/Insights access remains gated.

  Practice Insights now shows the four completed weeks newest first: Last week,
  2 weeks ago, 3 weeks ago, 4 weeks ago. Compact rows retain reported practice,
  practice days, Verified and Pristine. Total and average remain server-calculated.
  Absolute ranges are absent from these summaries; the current incomplete week
  is not added. Dates remain available in the separate statistic visualizations.
