Implemented contract
--------------------
Current, PIN-authenticated teachers can assign an existing Homework recipe or short
plain-text music-practice instructions to their exact assigned Class. Students see
Class-labeled Director's Choice separately from their personalized Weekly Loop
Homework. Assignments use Monday–Sunday America/Chicago weeks, including DST.
Current/future weeks support creation; expired work is read-only. The saved week
is fixed; cancel and create new work to change weeks.

Edits and cancellations append immutable versions with author teaching-assignment
identity, content, state, and timestamp. Directors can inspect version history.
Cancelled work remains visible as cancelled and is read-only. Stale edits require
a reload. Identical creation retries return the original saved assignment.
Assignment and version lists have bounded pagination.

The shared Homework instruction generator is reused without creating personal
Homework plans, targets, progress, completion, grades, attendance, practice credit,
or rewards. Custom content is escaped, bounded to a 120-character title and
1,000-character instructions, and normalizes browser line endings.

Authorization and privacy
-------------------------
Every reader/writer rechecks exact Program/Class, active Class, current entitlement,
and native authentication. Director access requires a current teaching assignment;
Owner/admin status and another Class never substitute for that assignment.

Student access requires current exact-Class membership, account eligibility, and
qualified guardian participation where required. Parent withdrawal, membership
withdrawal/holds, teacher changes, archived Classes, and entitlement loss remove
access. Work survives teacher changes, but existing parent permissions bound to a
previous teacher set do not authorize the replacement set. Current authorized
teachers retain Class work and its original author provenance.

P-Chart invitations do not grant assignment access. Class instructions are not
student activity history. Nothing grants comprehensive reporting, individual chart
sharing, school authority, or historical practice disclosure. Under-13 reporting
and the 26 excluded reporting fields remain unavailable. The 41-field reporting
implementation, approved Practice Rating calculations, guardian/KWS contract,
school legal-review gates, and protected P-Chart contract are unchanged.

Routes use native account/PIN proofs, same-origin and CSRF checks, strict bounded
forms/selectors, post-wait credential/session rechecks, no-store responses, and
browser privacy clearing. PostgreSQL uses the existing Program-first lock order
and READ COMMITTED requirement. No teacher/member lists are copied into assignments.
